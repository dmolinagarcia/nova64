## 3. Authoritative architecture snapshot

The synthesis doc is now the canonical reference; this is the compressed version.

**Compute.** W65C816S in PLCC-44 socket, native mode, PHI2 target **8 MHz** generated by FPGA-A; BE releases the bus. Three iCE40 TQ144 FPGAs: **FPGA-A** = northbridge (MMU + ASID TLB + HW walker, 1 MB cache, bus arbiter, PHI2, interrupt controller with priorities, 100 Hz system timer, UART, SPI-SD, I2C, debug port; ~93/107 pins used). **FPGA-B** = video/audio (taps the shared bus; 64 KB VRAM aperture at bank `$FE` gated by MMU's VRAM_SEL; RGB-TTL out; I2S; VGA bring-up; VSYNC IRQ; ~79 pins). **FPGA-C** = optional softcore 65816, footprint only. **RP2040** = embedded controller outside the bus (its W25Q16 is the board's only mandatory flash).

**Memory.** SDRAM **W9825G6KH 32 MB** is *the* main memory: 16,384 × 2 KB physical frames; controller target ~50 MHz (candidates: lawrie/blackicemx, niklasnisbeth/ice40-litedram, ZipCPU/zipstormmx). System SRAM **2 MB IS61WV102416 (10 ns, ×16), unified**: 1 MB cache (256-byte lines) + 512 KB page tables (≤16 resident tables) + 512 KB pinned (per-process bank `$00` + kernel). SRAM and SDRAM share one 16-bit bus behind FPGA-A → cache-line fill serializes; miss ≈ 200–300 ns. FPGA-B has its own **APS6404L 8 MB PSRAM (QSPI)** as chip RAM (framebuffer + audio DMA), outside the CPU hierarchy. Layout note: SRAM + SDRAM in a short comb next to FPGA-A.

**Virtual memory.** 16 MB per process, full paging, 2 KB pages (13-bit page # + 11-bit offset). Flat table: 8,192 PTE × 32 bit = **32 KB per process**. PTE: `FRAME[15:0]` + P·W·X·U·D·A·NC·PIN + `SW[7:0]` → 27-bit PA, 128 MB ceiling. TLB 32–64 ASID-tagged entries in EBR (no flush on context switch); walker ≈ 4 cycles on 10 ns SRAM. Faults via **ABORTB** (exact instruction retry), VPA = execute check, VPB = privilege transitions; fault registers at `$FF`: FAULT_ADDR, FAULT_CAUSE, CONTEXT, MODE. Bank map: `$00` per-process stack/DP + minimal privileged area (65816 requires vectors and PBR=0 handling in bank 0) · `$01` kernel 64 KB pinned · `$02–$FD` user · `$FE` VRAM aperture · `$FF` privileged I/O, never user-mappable. Frame allocator: bitmap; ABORT handler policy: legitimate heap/stack growth → allocate + retry, else kill. v1 loads eagerly; demand paging/swap post-v1.

**Boot (9 steps).** Power button → RP2040 (3V3 AO) → rail sequencing (1.2 V on, panel off) → FPGA config via SSPI (CRESET_B/CDONE) → gateware alive (PHI2, SDRAM init) → RP2040 reads `BIOS.BIN` from SD (FAT) into pinned SRAM → SD ceded via '3257 mux to FPGA-A's SPI-SD → RESB↑, CPU vectors through `$FFFC` → BIOS inits, mounts FAT read-only, loads `KERNEL.BIN`, jumps with an info block → kernel to prompt (= Apple II milestone at E6). BIOS leaves a residual JSL table (putchar/getchar/read-sector) until kernel drivers take over. Recovery: RP2040 can reclaim the SD over USB at any time.

**Power.** USB-C sink (5.1 kΩ CC + ESD) → **MCP73871** 1S charger with power path → SYS node → **TPS63020** buck-boost → 3V3 always-on; LDO 1.2 V (EN) for iCE40 cores; VCCPLL filtered per FPGA; VPP 2.5 V via BAT54 from 3V3; panel load switch. Boosts hang from **SYS, not VBAT** (works over USB with a dead battery): **PT4110** backlight (~1.5 W reserved, EN/PWM from RP2040) and **TPS61023** 5 V VBUS host (500 mA, EN on demand). 0 Ω jumpers per rail for bring-up. Battery 1S 3000 mAh, >10 h estimated; MAX17048 gauge + PCF8563 RTC on I2C; EC can shut down safely with a hung OS.

**Display/HID/audio.** 10.1″ 1024×600 IPS (ER-TFT101-1, HX8282) via RGB-TTL FPC-50 direct from FPGA-B at 51.2 MHz; pixel doubling 512×300 → 1024×600. GT911 capacitive touch on system I2C + INT. HID is USB-only via RP2040 PIO-USB + hub (PS/2 and matrix removed). PCM5102A I2S DAC. VGA via R-2R for bring-up. eDP/ANX6345 deferred as a future variant.

**OS & processes.** Small monolithic preemptive kernel in bank `$01`, mapped identically/privileged in every table. Syscalls via **COP** signature byte; Unix-style table (proc: exec·exit·wait·yield·sleep·kill / mem: sbrk·mmap·munmap·mshare / unified I/O: open·close·read·write·seek·stat·ioctl). Drivers = fixed 5-function interface (init·read·write·ioctl·irq_handler) exposed as `/dev/*`; framebuffer access = ioctl that maps `$FE` pages (no per-pixel write). FS: FAT on SD + minimal devfs. Scheduler: preemptive round-robin at 100 Hz; context switch = save A,X,Y,S,D,DBR,PBR,P,PC in PCB → write CONTEXT/ASID → restore (tens of µs, no TLB flush). Custom binary format: magic, entry, segments (vaddr/filesz/memsz/R-W-X); loader maps, zeroes BSS, maps stack, RTIs in.

**Toolchain.** Assemblers ca65 / 64tass. C: WDCTools and LCC-816 best available; Calypsi recommended (C99, large model, 24-bit pointers, JSL/RTL). cc65 and llvm-mos do **not** support the 65816. Recommended hybrid model: large-model code + fixed DBR for data. Kernel in C with asm only for vectors, context switch, MMU/cache-critical paths, startup; libc syscall stubs = `COP #SYS_n` + `RTL`. Gateware: Yosys + nextpnr-ice40 + IceStorm; simulate before hardware. Dev loop: build on PC → transfer via USB (RP2040) or SD → debug over serial console + FPGA-A debug port.

**Build plan.** E0 preparation (in progress) → E1 free-run → E2 SRAM+monitor → E3 SDRAM → E4 MMU+cache+protection → E5 video+audio → E6 SD+minimal OS+HID (**Apple II milestone**) → E7 multitasking → E8 portable+GUI (**Amiga milestone**). Optional off-critical-path: FPGA-C softcore, demand paging/swap, eDP panel variant. Each stage has an explicit TEST criterion (recorded in sheet M).
